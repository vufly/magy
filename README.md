# Magy

Magy is planned as a profile-aware launcher and MCP bridge for the official
Google Antigravity CLI (`agy`). This repository currently contains design and
handoff documentation only.

Start with [`docs/plans/v1/README.md`](docs/plans/v1/README.md).

Handoff guides:

- [`docs/handoffs/implementation.md`](docs/handoffs/implementation.md)
- [`docs/handoffs/review.md`](docs/handoffs/review.md)
- [`docs/handoffs/verification.md`](docs/handoffs/verification.md)

No implementation should proceed past the profile-isolation gate until two
separately authenticated profile homes are proven to retain distinct accounts.
